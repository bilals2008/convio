# SMS appointment reminders

Send automated SMS reminders, confirmations, and follow-ups to reduce no-shows and keep your customers informed.

## What you build

An SMS agent that handles appointment scheduling conversations — booking, rescheduling, reminders, and confirmations — via text message.

## Setup

1. **Connect Twilio** — add your Twilio credentials in Settings → Deployments.
2. **Create an agent** — write a prompt for scheduling conversations.
3. **Attach a knowledge base** — upload your availability, services, and policies.
4. **Add a booking tool** — connect your calendar or booking system via MCP or Composio.
5. **Deploy to SMS** — set the agent active and deploy to your Twilio number.

## Tips

- Keep SMS replies short — one question per message.
- Use the playground to test edge cases like double-booking and time zones.
- Set business hours so customers are not texted at night.
- Add Q&A pairs for common rescheduling and cancellation questions.
