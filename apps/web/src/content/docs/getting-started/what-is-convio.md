# What is Convio?

Convio is an open-source platform for building, deploying, and scaling AI agents across every channel. One agent definition, many places to reach people.

## Core concepts

An **agent** is the brain behind a conversation. It holds a model, a system prompt, and the tools it is allowed to call. Agents are scoped to an **organization**, so a team can share them without stepping on each other.

A **channel** is where an agent is published — the web widget, the API, or an integrated messaging surface. The same agent can run on several channels at once.

A **knowledge base** is a set of documents an agent can retrieve from, so its answers stay grounded in your own content instead of guessing.

## Why it exists

Most agent tooling stops at the prototype. Convio is built for the part after that: multi-tenancy, provider choice, per-key cost control, and channels that actually ship.
