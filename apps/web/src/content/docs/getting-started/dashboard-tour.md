# Dashboard tour

The dashboard is the home base for everything you build. This is what each area is for.

## Sidebar

The sidebar is scoped to the current organization. Use the org switcher at the top to move between workspaces — if you only see one, you have not been invited to any others yet.

## Quick stats

The overview shows the numbers worth checking first: total conversations, message volume, active agents, and token spend for the current period. Spend is the one to watch, because it is the one that surprises people.

## Agents

Where your agents live. Each row shows its status, model, and last activity. Click any agent to edit its prompt, tune model settings, or open the playground and talk to it directly.

## Conversations

Every message an agent has sent or received, across all channels, filterable by agent and organization. This is where you debug a bad answer: find the conversation, read the transcript, then fix the prompt that produced it.

## Settings

Organization settings, team members, provider keys, billing, and audit logs. Provider keys are per organization, so a team can use its own model credentials instead of the platform default.
