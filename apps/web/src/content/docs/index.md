# Introduction

Convio is an AI agent platform for customer-facing teams. You build agents — a model, a system prompt, knowledge, and tools — then deploy them to your website, WhatsApp, Slack, Telegram, or SMS.

## The core idea

An **agent** is the brain behind a conversation. A **deployment** is that agent published to a channel. Agents live inside an **organization**, which also holds your team, knowledge bases, provider keys, and billing.

## Where to go

- **New here?** Start with [Getting started](/docs/getting-started) — account, organization, first agent, team.
- **Building agents?** [AI agents](/docs/agents) covers models, prompts, tools, and testing. [Writing system prompts](/docs/system-prompts) and [Knowledge bases](/docs/knowledge-bases) go deeper.
- **Going live?** [Channels & deployment](/docs/channels) covers the widget and messaging channels. [Billing & usage](/docs/billing) covers plans and cost control.

## The five-minute version

1. Create an account and verify your email.
2. Create an organization.
3. Build an agent: model, system prompt, knowledge base.
4. Test in the playground until the answers hold up.
5. Set it `active`, deploy to a channel, and send a real message.
